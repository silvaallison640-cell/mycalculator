# 🧮 Mycalculator

Calculadora feita em Python que roda no terminal. Ela mostra um menu de operações e continua funcionando até você escolher sair.

## Funcionalidades

| Opção | Operação | Exemplo de entrada |
|:-----:|----------|--------------------|
| 1 | Adição | `2 3 5` → 10 |
| 2 | Subtração | `10 3 2` → 5 |
| 3 | Multiplicação | `2 4` → 8 |
| 4 | Divisão (quociente e resto) | `17 5` → 3 e resto 2 |
| 5 | Potência | `2 10` → 1024 |
| 6 | Raiz quadrada | `16` → 4 |
| 7 | Porcentagem | `20 150` → 30 |
| 8 | Fatorial | `5` → 120 |
| 9 | Ajuda | — |
| 0 | Sair | — |

## Como usar

1. Tenha o [Python 3](https://www.python.org/downloads/) instalado.
2. Baixe o arquivo `calculadora_python.py`.
3. No terminal, dentro da pasta do arquivo, execute: `python calculadora_python.py`
4. Escolha uma operação pelo número e digite os valores **separados por espaço**.

## Exemplo

    Operação: 1

    [ADIÇÃO]
    Digite os números que deseja somar: 2 3 5
    Resultado: 10
